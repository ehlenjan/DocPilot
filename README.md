# DocPilot

> An intelligent document assistant for macOS that learns your existing folder structure.

---

## Vision

Most document management systems require users to change the way they organize their files.

**DocPilot does the opposite.**

It learns your existing folder structure and helps you organize, rename and find documents faster.

No migration.

No proprietary database.

Your folders stay yours.

---

## Core Principles

- 📂 Your folder structure always remains unchanged.
- 🧠 The application learns from your decisions.
- 🔍 Every suggestion is explainable.
- 💻 Offline First.
- 🚀 Built with SwiftUI for macOS.

---
